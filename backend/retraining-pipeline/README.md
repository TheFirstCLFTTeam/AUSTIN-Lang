# Retraining Pipeline

This module handles the domain adaptation of the Whisper model. It allows the system to learn specialized vocabulary, accents, and code-switching by fine-tuning tiny "LoRA adapters" on top of the base model.

## Features
- **Data Extraction (WIP)**: Automatically pulls edited transcripts and audio from the system database. 
- **LoRA Training**: Uses Parameter-Efficient Fine-Tuning (PEFT) to train weights in 8-bit quantization (saving VRAM/RAM).
- **Incremental Learning**: Supports building new adapters on top of existing ones (v1 -> v2).
- **MERaLiON Integration**: Built-in support for testing with the MERaLiON multi-national speech corpus.

## Setup

1. **Install Dependencies**:
   ```
   pip install -r requirements.txt
   ```
   *Note: FFmpeg must be installed on the system path.*

2. **Configure Environment**:
   Ensure there is a `.env` file in this directory:
   ```env
   DATABASE_PORT=8002
   AUDIO_SUBMISSION_PORT=8000
   MANIFEST_PATH=data/manifest.jsonl
   OUTPUT_DIR=adapters/my_domain_v1
   ```

## Workflows

### 1. Standard Retraining (From Database) (WIP)
This workflow uses the data generated by users correcting transcripts in the AUSTIN-Lang dashboard.
```powershell
# 1. Fetch data from DB and create manifest
python dataset_builder.py

# 2. Run training round
python train.py
```

### 2. Testing with MERaLiON Dataset
Use this to verify the pipeline using external gold-standard Singlish data.
```powershell
# 1. Download and prep MERaLiON samples
python meralion_test_prepper.py

# 2. Train (settings loaded from .env or env vars)
$env:MANIFEST_PATH="data/meralion_manifest.jsonl"
$env:OUTPUT_DIR="adapters/meralion_v1"
python train.py
```

### 3. Incremental Retraining (Building on v1)
To improve an existing model without starting from scratch:
```powershell
$env:BASE_ADAPTER_PATH="adapters/meralion_v1"
$env:OUTPUT_DIR="adapters/meralion_v2"
$env:MANIFEST_PATH="data/new_collected_data.jsonl"
python train.py
```

## Output Artifacts
The training process produces a folder in `adapters/` containing:
- `adapter_model.safetensors`: The trained LoRA weights (~50MB).
- `adapter_config.json`: The configuration for the PEFT model.
- `tokenizer_config.json`: Ensuring text processing matches the model.

## Integration with Transcription Service
The `adapters/` directory is volume-mounted to the `transcription-service-2`. Once a folder (e.g., `meralion_v1`) appears in `adapters/`, the transcription service can use it immediately via the `domain` API parameter.

## Performance Notes
- **GPU**: Highly recommended (NVIDIA). Training will automatically detect CUDA.
- **CPU**: Fallback supported but slow (~30-60s per step). 50 steps = ~45 mins.
- **Memory**: The model is loaded in 8-bit, requiring ~3GB of VRAM or ~6GB of System RAM.
